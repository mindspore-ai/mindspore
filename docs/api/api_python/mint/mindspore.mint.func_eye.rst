mindspore.mint.eye
==================

.. py:function:: mindspore.mint.eye(n, m=None, dtype=None)

    返回一个主对角线上元素为1，其余元素为0的tensor。

    参数：
        - **n** (int) - 返回的行数。
        - **m** (int，可选) - 返回的列数。默认 ``None`` ，与 `n` 的值相等。
        - **dtype** (mindspore.dtype，可选) - 返回的数据类型。默认 ``None`` 。

    返回：
        Tensor
