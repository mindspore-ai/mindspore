mindspore.ops.frac
==================

.. py:function:: mindspore.ops.frac(x)

    返回输入tensor中每个元素的小数部分。

    .. warning::
        从2.9.0（不含）之后版本开始，该接口将发生非兼容性变更：

        - 参数 `x` 将重命名为 `input` 。

        变更后的接口签名为 ``mindspore.ops.frac(input)`` 。

    参数：
        - **x** (Tensor) - 输入tensor。

    返回：
        Tensor
