mindspore.ops.communication.is_available
==========================================

.. py:function:: mindspore.ops.communication.is_available()

    检查分布式模块是否可用。

    .. note::
        始终返回 `True`，因为MindSpore在所有平台上始终具有分布式能力。

    返回：
        bool，此分布式模块是否可用。
