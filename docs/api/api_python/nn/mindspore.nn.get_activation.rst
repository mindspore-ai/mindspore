mindspore.nn.get_activation
============================

.. py:function:: mindspore.nn.get_activation(name, prim_name=None)

    获取激活函数。

    .. warning::
        该接口已废弃，2.9.0（不含）之后版本将删除。

    参数：
        - **name** (str) - 激活函数名称。
        - **prim_name** (Union[str, None]) - 算子名称，默认值： ``None`` 。

    返回：
        激活函数。
